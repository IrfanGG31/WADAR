# D2–D8 — Kartu tugas ringkas (pecah jadi file DX.md sendiri saat hari itu dimulai)

DoD: test on_hand = Σ movements; seed bisa diulang (`pnpm seed:demo --reset`).

D3 POS: server action `recordSale` (idempotency_key, alokasi diskon/komisi largest remainder, unit_cost_snapshot, movements, update customer stats) dalam satu fungsi SQL/transaksi. UI kasir: cari, kategori, keranjang, diskon, metode bayar, pilih pelanggan by HP. DoD: 3 item < 20 dtk; double-submit tidak duplikat.

D4 Core: `core/stock.ts` (§7.1: EWMA, SS, ROP, days_left, status, reorder_qty, slow_moving) dan `core/finance.ts` (§7.2: R,C,F,S,GP,NP, margin per produk/kanal, dekomposisi, aturan SELL_BELOW_COST/FEE_HEAVY/DISCOUNT_HEAVY). Query agregat SQL (view/RPC). Beranda: 4 kartu + tren 7 hari + stok menipis. DoD: unit test + invarian dekomposisi.

D5 Layar: Stock Intelligence (tab Stok Produk / Prediksi & Rekomendasi, filter) dan Financial Insight (tab Ringkasan / Margin / Detail, donut kategori, margin per produk & kanal, kartu "kenapa untung berubah"). Narasi template deterministik. DoD: semua angka cocok dengan fungsi core; tampil rapi di 390px.

D6 Chat: Pengaturan kebijakan toko (form terstruktur) + FAQ; embedding FAQ & katalog (tanpa harga). View `chat_product_cards`. `/w/[slug]` widget + `api/chat`: retrieval (kebijakan + top-5 produk trigram + top-3 FAQ vektor) → generateObject skema §7.3 → guardrails (harga, larangan, janji, confidence<0.6) → eskalasi. Inbox sederhana (daftar percakapan, ambil alih, balas). DoD: 15 pertanyaan demo benar; diskon → eskalasi; tidak pernah menyebut HPP.

D7 Konsultasi: `api/consult` streamText + tools (get_business_snapshot, get_sales_summary, get_profit_breakdown, explain_profit_change, get_stock_status) memakai fungsi core; grounding angka (§7.4) + 1× retry; "Insight minggu ini" via tombol (top-3 aturan → narasi). Log token & biaya ke `ai_runs`. DoD: 10 pertanyaan demo angka tepat. Opsional: WA nomor test.

D8 Polish & Freeze: empty/loading/error state, PWA manifest + ikon, DEMO_SAFE cache, reset demo, cek Lighthouse mobile, uji skenario 3× di HP, deploy final 21.00 → freeze.
